# 📚 Project Management Reviewer — CTPRJMGT Midterm

An interactive web-based study companion for the **CTPRJMGT — Project Management** midterm examination, covering all five lessons.

## 🔗 Live Site

> **[View the Reviewer →](https://your-vercel-url.vercel.app)**
> *(Update this link after deploying to Vercel)*

## ✨ Features

- **5 Comprehensive Lessons** — detailed notes with visual diagrams
- **35-Item Practice Quiz** — multiple choice with instant feedback & explanations
- **Dark Mode** — toggle between light/dark themes (auto-saves preference)
- **Color-Coded Highlights** — key terms are visually emphasized for better retention
- **Mobile Responsive** — works on phones, tablets, and desktops
- **Zero Dependencies** — single HTML file, no frameworks needed

## 📖 Lessons Covered

| # | Lesson | Key Topics |
|---|--------|------------|
| 1 | Introduction to PM | Project definition, 7 attributes, triple/quadruple constraint, 10 knowledge areas, PMI, ethics |
| 2 | PM & IT Context | Systems approach, 4 frames, org structures, culture, Agile/Scrum, virtual teams |
| 3 | Process Groups | I-P-E-M-C, integration mapping, PRINCE2, RUP, Six Sigma |
| 4 | Integration Management | SWOT, NPV/ROI/payback, project charter, change control, closing |
| 5 | PM Methodologies | 9 SDLC models, selection criteria, Waterfall vs Agile comparison |
